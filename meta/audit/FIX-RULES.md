# 修复规则（所有修复必须遵守）

## 总原则

1. **只改矛盾的那一侧，不改被后文依赖的那一侧。**
2. **优先删数字，其次改数字，最后才加句子。**
   - 绝对日期 → 相对表述（「十月二十二日十四时」→「明天下午两点」）
   - 不合理吨位 → 只留尺度（「十二万吨的船」→「八百米的船」）
   - 算不通的年龄 → 相对表述（「四十六年」→「这些年」）
   - 航速矛盾 → 「比预计早到两个钟头」
3. **不改剧情、不增删情节、不改人物关系、不改章末钩子。**
4. 允许加**一句**衔接（不超过 40 字），只在两章之间缺动作时。
5. 每改一处，必须确认原句在文件里唯一存在，改完 grep 不到旧句。
6. 改完跑 `scan_hard_indicators.py`，block 必须为 0。

## 报告用法

每份报告（`chXXX-YYY.md`）里的「问题」表：
- 硬矛盾：按上表与总原则改。
- 软矛盾：能一句话改就改；要动结构的，标「跳过」。
- 疑似：查 `SUSPECTS.md` 的默认动作；没有列入 A/B 档的，一律不改。

## 输出

- 改动写入正文文件。
- 清单写入 `meta/audit/fix_XXX-YYY.md`，格式：`| 章 | 原句 | 改为 | 依据 |`
- 无法改的写「跳过」并给一句理由。
