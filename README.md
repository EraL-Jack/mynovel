> 一个在轨道垃圾带拆废铁的拾荒者，捡到一枚没有编号的黑匣子。匣子里是他妹妹的声音，说的是"别来救我"。三个小时后，通缉令贴满了旧港，落款时间比他拆开匣子还早三个小时。

## 刷新机制

- **每写完一章**：回填 `tables/mainline.md` 的知识状态与伏笔状态，更新 `meta/status.md`。
- **每写完五章**：校对 `bible/` 里被正文改动的设定（新地名、新称谓、新规则）。
- **每二十章**：全盘对账一次，检查伏笔回收、钩子轮换、爽点间隔、角色弧光进度。
- 设定以正文为准。正文里写死的细节，回填进设定集；设定集里与正文冲突的，改设定。

## 命名约定

- 正文文件：`chNNN.md`，只带编号，不带剧情。
- 章内标题只用中性词（地名、时间、事件名），不写转折与结果。
- 中间件按用途命名，不按内容命名。
