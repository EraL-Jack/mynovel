## 主角

### 陆昭 ｜ 功能位：主角

| 项 | 内容 |
|---|---|
| 年龄 | 24 |
| 出身 | 坟场拾荒者。母亲是"赫耳墨斯计划"研究员，UL 213 年失踪。父亲不详。 |
| 同调率 | 51%（D 级偏下，勉强能开机甲）。接入黑匣后稳定 88%，爆发 97%。 |
| 欲望 | 把妹妹陆星从地联手里弄出来，找一个没人认识他们的地方活下去。 |
| 恐惧 | 变成"不是自己"的东西。他见过空壳，记得那双眼睛。 |
| 底线 | 不拿活人的命换自己的路。 |
| 弧光 | 从"只想带妹妹逃走的人"到"决定人类往哪走的人"。触发点：卷三环城陷落，他第一次为了大局放弃了一个人。 |
| 凭什么 | 十五年拾荒练出的"读甲"：听声音就知道哪根轴断了。别人看图纸，他听机器喘气。 |
| 每次的代价 | 记忆白斑。用得越狠，忘得越多。第一次忘的是老鬼的脸。 |
| 可恨之处 | 为了陆星，他可以不管别人死活。卷三他真的这么干了一次，害死了一船人。 |

**关系网**

- 与陆星：表面是兄妹，底下是彼此唯一活着的理由。张力点：陆星不想被救，她想让他走。
- 与老鬼：表面是船长与伙计，底下是父子。张力点：老鬼瞒着他黑匣的来历。
- 与苏黎：表面是战友，底下互相看不顺眼又离不开。张力点：她是火联的人。
- 与雷戈：表面是教官与学员，底下是师徒。张力点：雷戈效忠的体制正是害陆昭的体制。
- 与韩铎：表面是官与民，底下是猎人与猎物。张力点：韩铎知道他母亲是谁。
- 与裴烬：表面是敌人，底下是同一批实验的两个结果。张力点：裴烬选了"成为新人类"，陆昭选了"当人"。

**声线**：话少，短句，爱用具体数字。损人的时候不带脏字，专挑对方最在意的地方说。急了下意识说坟场黑话（"这甲喘得跟老鬼的肺一样"）。

**自称 / 称谓**：自称"我"。被叫"陆昭""昭子"（老鬼、耗子）、"垃圾佬"（韩青一伙）、"编号 037"（安全局档案里）。
