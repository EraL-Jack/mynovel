# 大纲（四级）

> 版本：v1.0。L1 不动；L2 随卷推进回填；L3 每 20 章滚动刷新一次。

---

## L1 · 一句话大纲

为了在七十二小时里洗掉"盗窃军械"的死罪、把妹妹从地联手里捞出来，坟场拾荒者陆昭必须顶着通缉混进猎户座军团的补录选拔，否则他会被公开处决，妹妹会被送进"门"；挡路的是把军案做成铁案的安全局副局长韩铎，而脑内那枚来历不明的黑匣，每用一次就让他忘掉一点自己。

**可证伪自检**：谁要什么（陆昭要活命和妹妹）、什么挡着（韩铎 + 整个体制）、代价（记忆）——三样都能复述。

## L2 · 卷部状态栏

### 卷一 · 坟场（第 1–40 章）

```
卷初状态：处境 坟场拾荒者，欠债，妹妹三天前失联 ／ 已握资源 一艘破船、一副野接口、51% 同调率 ／ 未解悬念 妹妹为什么说"别来救我"
本卷目标：拿到军团选拔资格，查清妹妹被谁带走
主要阻力：韩铎要做实军案，把陆昭做成"盗卖军械"的替罪羊
卷中小高潮：第 3 章，当众打脸韩青，47 秒团灭精英队
卷末状态：处境 军团正式机师，身份半公开 ／ 资源 Ⅲ型甲"灰狗"、废料班五人 ／ 代价 老鬼死，记忆开始出现白斑
卷末悬念：牧者号已经离开地月系，妹妹不在船上
```

### 卷二 · 红沙（第 41–90 章）

```
卷初状态：处境 借调火星参加交流赛 ／ 资源 Ⅲ型甲、雷戈的信任 ／ 未解悬念 牧者号去了哪
本卷目标：在火星找到"牧者号"的货运记录，活着回来
主要阻力：火联元帅索恩要拿陆昭做开战借口；教团在火星布了局
卷中小高潮：第 58 章，红沙竞技场十连胜，改造人观众倒戈喊他名字
卷末状态：处境 战争爆发，地月航线断 ／ 资源 Ⅳ型甲"白鸦"、苏黎入队 ／ 代价 身份公开，成了两边都要杀的人
卷末悬念：火联的"禁甲"是谁给的图纸
```

### 卷三 · 外环（第 91–150 章）

```
卷初状态：处境 通缉犯，躲在外环 ／ 资源 一艘护卫舰、十几个亡命徒 ／ 未解悬念 禁甲图纸来源
本卷目标：守住铁砧港，换一张去深空的船票
主要阻力：三方舰队在铁砧外海决战，环联准备卖他换和平
卷中小高潮：第 120 章，单舰冲阵，击沉旗舰
卷末状态：处境 环城陷落，地联崩溃 ／ 资源 母舰"锈狗号"（继承老鬼的名字） ／ 代价 他为救陆星，放弃了一船人
卷末悬念：陆星自己走进了"门"
```

### 卷四 · 深空（第 151–205 章）

```
卷初状态：处境 人类三方残军的名义领袖 ／ 资源 一支杂牌舰队 ／ 未解悬念 "门"是什么
本卷目标：追上牧者号，把陆星带回来
主要阻力：牧者；裴烬；舰队内部的分裂
卷中小高潮：第 178 章，裴烬在门前的选择
卷末状态：处境 站在门前 ／ 资源 黑匣的完整权限 ／ 代价 他忘掉了陆星的脸
卷末悬念：门开了，另一边是人
```

### 卷五 · 新历（第 206–250 章）

```
卷初状态：处境 人类与"场"对峙 ／ 资源 残存舰队 + 黑匣 ／ 未解悬念 人类要不要"进化"
本卷目标：关上门，或者走进去
主要阻力：牧者的最后一问
卷末状态：处境 新历元年 ／ 资源 一个没有等级的联合体 ／ 代价 他记得的只剩名字
卷末悬念：无（收束）
```
