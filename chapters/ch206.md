# 第二百零六章 脚下

那只手在陈胖肩上，五指张开，拇指压在领口。

陆昭举着匣，站在十五米外。光从缝里出来，落在冰上，把两个人的影子拉在墙上。

墙上只有一个人的影子。

他没喊。

“陈胖。”陆昭说，“名单第七页，念给我听。”

陈胖抬头。他先看陆昭的脸，再看陆昭举匣的手，然后顺着陆昭的眼睛，往自己肩膀上看。

他的手停在纸角上。

“第七页是空的。”陈胖说。

“念。”

“第七页三行，划了两行。”陈胖把名单合上，屁股往台子前头挪了半尺，“剩一行写‘余十人待核’。”

肩上那只手收紧。陈胖的领口往上走，勒出一圈褶。

“你手劲不小。”陈胖说，“兄弟，先松开。这领子是借的。”

背后的人不答话。

陆昭往前走三步。石铁从东头过来，铁棍拎在右手，走得不快，脚落在砂上没声。

“别过来。”背后的人开口，嗓子哑的。

“我不动。”陆昭站住，“你也别动。你手底下这人一百九十斤，你拖不动他。”

“我拖得动。”

“拖动了你也出不去。这冰场四个门，门口都站着人。”

那人沉默两秒。

“那你让我走。”

“走哪儿。”

“外头。”

陆昭把匣往下放一寸，光压低，墙上那道影子跟着矮了半截。

“你叫什么。”他问。

那人张了张嘴。

石铁的棍到了。

棍从下往上，砸在那人肘弯。骨头响一声，胳膊往下一沉。陈胖一矮身，从台边滚下去，一百九十斤砸在冰上，砸出一声闷响。

那人从袖子里抽出一根冰凿，三十公分，一头尖，反手往下扎。

陈胖抬左臂去挡。

冰凿扎进小臂内侧，从外头露出半寸。

陈胖叫了一声，声音压在喉咙里，像牛。

石铁第二棍打在那人后背。那人往前扑一步，回身一拳，砸在石铁肋上。石铁退两步，肋上的带子绷开，人靠在冰墙上。

苏黎在东头开枪。

一声脆响。低装药，子弹打在那人右肩，肩上的棉袄鼓了一下，血从里头冒出来。

那人跪下去，冰凿掉在冰上，弹了一下。

石铁扑上去，一棍压住他后颈，膝盖顶在腰上。

冰场里一千多人往后退。砂在脚底下响成一片。

陆昭走过去，蹲下。

那人三十来岁，胡茬，左眉上一道疤。血从肩上冒出来，在冰上摊开一块，黑砂粘在血边上。

“谁造的你们。”陆昭问。

那人抬头看他，笑了一下，牙上全是血。

“你也是复制的。”

陆昭没动。

“门里照过你。”那人说，“你脚底下……”

头往下一沉，抵在冰上。眼睛睁着。

冰场里没人出声。

陆昭站起来。

他低头看自己的脚。

光从他手里出。影子在他背后，长长的一条，拖到升降台底下。

“你举着灯，看不见自己。”耗子在他身后说。

陆昭把匣往冰上按。

“把人收起来。”他说，“死的一个，站五个。六个。”

“四个怎么收。”石铁问。

“绑到西边冰墙下，隔两米一个。”

石铁把四个人带到墙下。抱棉袄的女人，抱铝饭盒的男人，驼背的老太太，还有一个十七八的姑娘。

他们不挣，也不跑。石铁拿绳，一人两道，绑在墙上的管子上。

光还亮着。墙上的影子只有绑人的那两个。

苏黎走到女人面前。

“你叫什么。”

“周淑兰。”

“哪年生的。”

“四十二年。”

“你男人呢。”

“死了。”女人说，“死在冰九站，三月十一，塌方。”

苏黎转头看台子这边。陈胖坐在冰上，一只手按着另一只手，脸白的。

“名单上有。”陈胖说。

“你记得他长什么样吗。”陆昭问。

女人看着他，想了一会。

“右眼下面一颗痣。”她说，“黄豆大。”

陆昭不出声。

“我记得。”女人说，“我什么都记得。我记得他死那天我在煮面，面下锅，水刚开。我记得他的手套在门口，右手那只，食指破了个洞。”

“那你为什么不挣。”

“挣了去哪儿。”

“白屋里的光什么颜色。”陈胖在台子那边问。

“白的。”女人说，“照在墙上，人没有影子。”

“你知道。”

“知道。”女人说，“进去的时候有，出来就没了。头一天我摸了半天墙。”

“那你还站在这儿。”苏黎说。

“没地方去。”

老太太一直没说话。她手里那根拐，石铁给她绑在腕子上，没拿走。她拿拐头在冰上点了两下。

“小子。”她说，“你这灯亮多久。”

“三分钟。”陆昭说。

“灯灭了，我们也在这儿。”老太太说，“跑不远，腿不行。”

陆昭把视线挪开。

人堆东侧有人在动。一个男人往外挤，挤得急，撞翻了两只水桶。

石铁带人过去，把人按在冰上，反手拖回来。

拖到光里，陆昭看见他的脸。

胡茬，左眉上一道疤。跟冰上躺的那个一模一样。

“这个呢。”苏黎问。

“也带过来。”陆昭说。

男人跪在冰上，两只手绑在背后。他看看冰上那个，又看看陆昭。

“我不认识他。”他说。

“你叫周海。”

“我叫周海。”

“他叫什么。”

男人低头看那张脸，看了半分钟。

“他也叫周海。”他说，“船上一共两个我，我数过。一个在货舱，一个在白屋门口。我跟他说话，他也跟我说话。”

“说什么。”

“我说‘你是我’，他说‘你是我’。”男人说，“一个字都不差。我说第二句，他接得比我快。”

“你上船那天吃了什么。”

“豆饼两片，汤一碗。”男人说，“汤是凉的，碗底有沙。”

“他呢。”

“他说的一样。”男人说，“他说豆饼两片，汤一碗，碗底有沙。他说的比我先。”

陆昭蹲下去。

“你左肩上有东西吗。”

“一块胎记。”男人说，“我娘说生下来就有。”

他把领口扯开。左肩上一块青，巴掌大。

陆昭把死人领口的扣子解开一颗。左肩上一块青，巴掌大。两块青并在一起，形状一样，边上缺的那一小角也一样。

陆昭站起来。

他往人堆里看。一千二百人，有坐的，有站的，有抱着孩子哄的。

“把他绑过去。”陆昭说，“跟他站一排。”

石铁把周海提起来，绳头绕在管子上，绑在姑娘旁边。五个人站成一排，墙上一道影子也没有。

“五个。”陆昭说。

石铁把铁棍换到左手，右手在裤子上蹭了一下。

人堆里一个老头往前挪了半步。

“小同志。”他说，“你拿灯照我们，谁照你。”

冰场静了一下。

“我照。”陆昭说。

“照得出来吗。”

陆昭没答。

“照不出来，你就跟我们一样。”老头说，“灯在你手里，你说谁没有影子，谁就没有。”

林雾从台边站起来，本子摊在手上。

“这一千二百一十四个名字，六个没影子。”他说，“六个写什么。”

“写编号。”陆昭说。

耗子把医药箱拖到陈胖身边，剪开袖子。

小臂上一个洞，前后两个口，血一阵一阵往外冒。苏黎倒止血粉，粉压不住，血把粉冲开。她换纱布，塞进去，胶带绕六圈。

陈胖咬着自己的袖口，额头上全是汗。

“六个。”他说。

“什么。”

“死一个，站五个。”陈胖说，“账对上。”

“你少说两句。”

“少说两句我疼。”陈胖说，“让我说。”

苏黎把手套上的血在裤子上擦了擦，站起来。

她看陆昭的时候，眼光在他脚上停了一下，又抬起来。

“你上次照过自己吗。”

“没有。”

“那就照。”

林雾蹲在台边，笔在纸上写了一行，划掉，又写一行。

韩青在拖板上把脸转开了。

耗子站在一边，手里捏着表笔，不看他。

陆昭掐了一下自己的手背。皮破了，血珠冒出来。疼。

冰上躺的那个也疼过。肩上一个洞，也流血，血也是红的，也在冰上凝。

复制的跟人一样会疼。

他弯腰，把匣从手里放下去，面朝上，按在冰面上。

“退后。”耗子说。

陆昭往后退。

一步。两步。三步。四步。五步。

光从冰面往上散，往四面拉。冰墙上的影子一下长了一倍，绑在管子上的四个人，影子一个也没有，绳子的影子倒是有四道。

他的影子应该在他脚后头，长长的一条，一直拉到升降台。

他再退一步。

匣上的缝灭了。

最后一个孔跟着灭。

冰场黑到底。木星的光从窗户外头进来，蓝白的，照不出三米。

黑里，耗子蹲下去摸电池。

“还有一块。”他说，“四分钟。”

“照我。”
